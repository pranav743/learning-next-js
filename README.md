# Boxen Assignment - First External NPM Module

This project demonstrates the use of the `boxen` NPM package to display messages in different box styles.

## Setup

1. Initialize the project:
   ```bash
   yarn init -y
   ```

2. Install the boxen package:
   ```bash
   yarn add boxen@5.1.2
   ```

## Running the Project

```bash
node index.js
```

## Features

The project displays a message "I am using my first external module!" with the title "Hurray!!!" in the following box styles:

1. **Classic** - Default border style
2. **SingleDouble** - Mixed single and double borders  
3. **Round** - Rounded corners

## Dependencies

- `boxen@5.1.2` - Creates boxes around strings
